# Coffee-shop-priskalkulator

 I dette prosjektet  laget  for en priskalkulator for en kafé og Programmet spør brukeren hvilken type kaffe de ønsker, hvilken størrelse de vil ha, og om de vil drikke kaffen på kaféen eller ta den med.
Programmet regner deretter ut totalprisen basert på valgene brukeren gjør.
Dette kan programmet
Velge mellom forskjellige typer kaffe
Velge størrelse på kaffen
Velge mellom å drikke kaffen på kaféen eller ta den med
Regne ut totalprisen
Gi beskjed hvis brukeren skriver inn et valg som ikke finnes
Kaffe på menyen
Espresso
Americano
Latte
Cappuccino
Macchiato
Mocha
Flat White
