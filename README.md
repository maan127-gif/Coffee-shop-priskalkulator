# Coffee-shop-priskalkulator

 I dette prosjektet  laget  eg en priskalkulator for en kafé. Programmet spør brukeren hvilken type kaffe de ønsker, hvilken størrelse de vil ha, og om de vil drikke kaffen på kaféen eller ta den med.
Programmet regner deretter ut totalprisen basert på valgene brukeren gjør
